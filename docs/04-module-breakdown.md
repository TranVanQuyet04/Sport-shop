# 04. Module Breakdown

## Auth Module

Backend:
- Register API.
- Login API.
- Logout API.
- Refresh token API.
- Forgot password API.
- Reset password API.
- Current user API.
- Role-based authorization.

Frontend:
- Login page.
- Register page.
- Forgot/reset password pages.
- Auth store.
- Header account menu.
- Protected route handling.

Owner đề xuất:
- Backend Auth: 1 member.
- Frontend Auth: 1 member.

## Catalog Module

Backend:
- Brand CRUD.
- Category CRUD.
- Sport CRUD.
- Color CRUD.
- Size CRUD.

Frontend:
- Admin managers.
- Storefront navigation.
- Product filters.

Owner đề xuất:
- Backend Catalog: 1 member.
- Frontend Admin Catalog: 1 member.

## Product Module

- Product CRUD.

- Product public listing.

Frontend:
- Product manager.
- Product listing page.
- Product detail page.
- Product card.
- Related products.

Owner đề xuất:
- Backend Product: 1-2 members.
- Frontend Product: 1-2 members.

## Cart Module
